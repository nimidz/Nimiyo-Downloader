# Nimiyo v3.0.0 — What's New?

## 🚀 Major Rewrite
- **Native Android App:** Rewritten from the ground up as a native Android application (the WebView version has been postponed).
- **Performance & Stability:** Resolved issues with the media player, excessive resource usage, device overheating, and MixTools audio stuttering.
- **Redesigned UI:** Cleaner, more organized interface with settings relocated into their relevant menus.

> Nimiyo is now available in two editions: **Nimiyo YTDLP** and **Nimiyo Lite**.  
> 👉 [Read the Version Differences](https://github.com/nimidz/Nimiyo-Downloader#-two-editions-nimiyo-vs-nimiyolite)

---

## ✨ New Features
- **Nimiyo YTDLP:** Powered by `yt-dlp` and `FFmpeg` for broader platform support (with certain limitations).
- **Nimiyo YTDLP:** Added new **QuickSave** settings.
- **Nimiyo Lite:** Added default scraper server selection and **QuickSave** settings.
- **Both Versions:** Added new music playback settings, including *Pause On*, *Resume On*, *Always Play On*, *Volume Boost*, *Playlist Button*, and more.
- **Both Versions:** Added lyrics customization options, including background appearance, display layout, custom fonts, and more.
- **Both Versions:** Added media type filtering (Audio, Video, and Image) in **Download History**.

---

## ⚙️ Improvements
- **Download History Player:** Upgraded the built-in media player and overall playback performance.
- **MixTools:** Added a new **Echo** effect to Reverb.
- **UI/UX:** Refined interface and customization controls across both editions.

---

## Attention Before Downloading
- **Android 5.0+:** Supports both 32-bit (`armeabi-v7a`) and 64-bit (`arm64-v8a`) devices.
- **Android 10+:** 64-bit build is recommended for optimal performance.
- **Nimiyo Lite (Universal APK):** Ultra-lightweight single installer (~3.7 MB) compatible with all Android architectures.

Not sure which build to pick? [Compare Nimiyo YTDLP vs. Nimiyo Lite](https://github.com/nimidz/Nimiyo-Downloader#-two-editions-nimiyo-vs-nimiyolite).
